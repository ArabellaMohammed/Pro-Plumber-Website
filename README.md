## Project Overview
This project involves the redesign and development of a website for Pro Plumber Pietermaritzburg, a plumbing business serving customers in Pietermaritzburg, Hilton, Howick and surrounding areas. The purpose of the project is to create a simpler, clearer and more organised website that allows customers to easily find information about the business, available plumbing services, emergency assistance, enquiries, contact details and business locations.

The website consists of five main pages: Home, About Us, Services, Enquiry and Contact Us. The project will be developed in three stages. Part 1 focuses on planning, research and HTML development. Part 2 will focus on CSS styling and responsive design while Part 3 will add JavaScript functionality, form validation, SEO, final testing and deployment. The completed website is intended to provide Pro Plumber Pietermaritzburg with a professional and trustworthy online presence that is easy for customers to navigate and use.

## Website Goals and Objectives
The main goal of the Pro Plumber Pietermaritzburg website redesign is to create a simpler, clearer and easier to use website for customers. The success of the website can be measured through website visitors and enquiries submitted through the website.

The website aims to:
- Organise the most important information into five simple pages.
- Use one Services page instead of multiple separate service subpages.
- Make it easier for customers to quickly find plumbing services, emergency assistance, service areas, contact details and quotation information.
- Increase website traffic and help more potential customers in Pietermaritzburg and surrounding areas discover the business.
- Maintain a professional and trustworthy online presence.
- Keep the website organised, easy to navigate and focused on the information customers are most likely to need.

## Key Features and Functionality

The Pro Plumber Pietermaritzburg website includes the following key features and functionality:
- Consistent navigation links that allows users to move between all five pages.
- A Home page with a short introduction to the business, plumbing services, emergency plumbing information and links to request assistance.
- An About Us page with information about the business background, mission, vision and commitment to professional service.
- A Services page that organises the main plumbing services into clearly labelled sections with short descriptions.
- An Enquiry page with a form where customers can provide their name, email address, telephone number, address, required plumbing service and a description of the plumbing problem.
- A Contact Us page with Pietermaritzburg and Hilton contact information, map links, emergency plumbing information and social media links.
- Relevant plumbing images to support the written content.
- Clear links that direct customers to important actions such as making an enquiry or contacting the business.
